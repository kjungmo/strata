\section{Reproduction}\label{app:repro}

\sname\ is released under the Apache-2.0 license at \url{https://github.com/kjungmo/strata} and targets ROS~2 Humble.

\noindent\textbf{Code pin.} The engine (\code{strata\_core}), the node (\code{strata}) and the check scripts (\nolinkurl{scripts/}) of the repository \url{https://github.com/kjungmo/strata} that this paper describes are those of commit \code{a7559d4} (19 October 2026), which adds the evidence model \code{sprt}; the experiment harness, the result files and this manuscript were completed after that commit without changing those three directories, and the number check compares their tree identifiers with that commit's. The first release of this manuscript pinned an earlier commit with the v0.1 evidence rule (tag \code{paper-v1}); the pin moved once, on purpose. The harness runs every seeded experiment in two arms: the \emph{legacy} arm, the v0.1 arithmetic with the explicit parameters of the first release, reproduces the earlier result files byte for byte (\nolinkurl{paper/experiments/check_legacy_equivalence.sh}), and the \emph{sprt} arm writes new files \nolinkurl{results/*\_sprt.csv}.

\noindent\textbf{What reproduces.} \nolinkurl{paper/experiments/check_reproduction.sh} rebuilds the harness from a clean checkout and requires every result file of E0--E3, E5 and E6 (both arms) and of E7 to come out byte for byte; \nolinkurl{paper/experiments/reproduction_log.txt} lists the compilers with which it did (GCC~9.4.0 with libstdc++, on one x86-64 Linux host). The result is not independent of the C++ standard library. The streams come from \code{std::mt19937}, whose output the standard fixes, through three standard distributions, whose algorithms it does not fix. With clang~23.1.2 and libc++ (\nolinkurl{check_stdlib.sh}, record in \nolinkurl{results/stdlib_libcxx/}), 15 of the 19 seeded result files are byte-identical and four differ: the two E1 files, the E0 door file and the E6 confusion file. These are the experiments whose outcome depends on integers drawn with \code{std::uniform\_int\_distribution} (mover cells in E1's \code{grid2d} runs, door phases in E0 and E6). Under libc++ the final \code{grid2d} precision at high clutter in E1 is 0.9583 with 168 predicted cells instead of 0.9253 with 174, and every other final value of Table~\ref{tab:e1} is unchanged; five of the 20 E0 door medians move by one window (at $\delta{=}0.1$, 20 to 21 and 23 to 24) and the selected levels do not change; and 1976 instead of 1960 of the 2000 aperiodic cells of E6 are Static with the shipped defaults. E5's confusion draws door phases the same way, but its counts do not depend on the phases and its file is identical. 17 of the 20 result files of the sequential-test arm and E7 are byte-identical and three differ (the E0 door file, the E6 confusion file and the E4 cell counts of the sequential-test arm), again the files that depend on integers or reals drawn with a standard distribution; E7 draws from \code{std::mt19937\_64} directly and is identical. No third standard library was tried.

\noindent From the repository root:
\begin{itemize}
  \item Core engine and unit tests, no ROS required (continuous integration runs the same build with g++, Eigen3 and GoogleTest on \code{ubuntu-latest}):
\begin{quote}\small\ttfamily
cmake -S strata\_core -B build -DSTRATA\_CORE\_BUILD\_TESTS=ON\\
cmake -{}-build build \&\& (cd build \&\& ctest)
\end{quote}
  \item Unit tests, the calibration E0 (seeds from 20260928), experiments E1--E4 (seed 12345), E5 (calibration seeds from 30260928, evaluation seeds from 40260928) and E6 (sweep seeds from 50260928), writing the CSVs under \nolinkurl{paper/experiments/results/}. E0--E3, E5 and E6 rewrite their files byte for byte. E4 reads the wall clock: this script writes its output to \nolinkurl{paper/experiments/build/e4_throughput_local.csv} and fails if a cell count or byte estimate differs from the committed one (\nolinkurl{check_e4_local.py}); timings for the paper are recorded separately with \nolinkurl{paper/experiments/measure_e4.sh}. The comparison columns of Table~\ref{tab:fix} are the same harness built against the v0.1.0 \code{strata\_core} (\nolinkurl{results/pre_fix_2026-09-28/}), against the centred engine before the significance test (\nolinkurl{results/pre_calibration_2026-09-28/}) and against the engine with the single-read-out level (\nolinkurl{results/pre_spending_2026-09-28/}):
\begin{quote}\small\ttfamily bash paper/experiments/run\_all.sh\end{quote}
  \item Tables and plot data of this paper, and the number check (\nolinkurl{paper/arxiv_ref/NUMBERS.md}). The check regenerates every table and plot-data file and compares it with the committed one. For the hand-written text it locates each numeral and requires it to be tied to a value recomputed from the result files or the code, or to be listed as structural with a reason (an experiment design constant restated from the harness, a symbol in a formula, a plot layout value). A numeral that is neither fails the check. Its limits are these. Structural numerals, among them the scenario sizes of \S\ref{subsec:setup} and the design constants written as symbol and value, are not parsed from the harness; they are kept in a committed list (\nolinkurl{paper/arxiv_ref/structural_numerals.tsv}), so that changing one fails the check until the list is rewritten on purpose. A numeral that is tied to a recomputed value only by being equal to it, and not by its sentence, could be exchanged for another recomputed value without the check noticing; \nolinkurl{NUMBERS.md} gives the count of each kind.
\begin{quote}\small\ttfamily python3 paper/arxiv\_ref/tools/make\_artifacts.py\\
python3 paper/experiments/number\_guard.py\end{quote}
\end{itemize}
Alternative backends can be replayed against the reference scenario of the unit test \nolinkurl{Integration.WallStaticMoverTransientDoorPeriodic}.
