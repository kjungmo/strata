\section{Reproduction}\label{app:repro}

\sname\ is released under the Apache-2.0 license at \url{https://github.com/kjungmo/strata} and targets ROS~2 Humble.

\noindent\textbf{Code pin.} The engine (\code{strata\_core}), the node (\code{strata}) and the check scripts (\nolinkurl{scripts/}) described in this paper are those of commit \code{312b09c} of that repository (11 October 2026). The experiment harness, the result files and this manuscript were completed after that commit without changing those three directories, so the repository revision that carries this paper contains exactly that code. From a fresh clone of that revision, \nolinkurl{paper/experiments/check_reproduction.sh} rebuilt the harness and rewrote every result file of E0--E3 and E5 byte for byte with two compilers, GCC~9.4.0 and GCC~14.3.0, both with libstdc++ on one x86-64 Linux host (\nolinkurl{paper/experiments/reproduction_log.txt}). The seeded streams use the random distributions of the C++ standard library, whose output is implementation-defined, so another standard library may produce other streams; none was tried.

\noindent From the repository root:
\begin{itemize}
  \item Core engine and unit tests, no ROS required (continuous integration runs the same build with g++, Eigen3 and GoogleTest on \code{ubuntu-latest}):
\begin{quote}\small\ttfamily
cmake -S strata\_core -B build -DSTRATA\_CORE\_BUILD\_TESTS=ON\\
cmake --build build \&\& (cd build \&\& ctest)
\end{quote}
  \item Unit tests, the calibration E0 (seeds from 20260928), experiments E1--E4 (seed 12345) and E5 (calibration seeds from 30260928, evaluation seeds from 40260928), writing the CSVs under \nolinkurl{paper/experiments/results/}. E0--E3 and E5 rewrite their files byte for byte. E4 reads the wall clock, so the script writes its timings to \nolinkurl{paper/experiments/build/e4_throughput_local.csv}, prints them beside the committed reference and fails if a cell count or byte estimate differs from it (\nolinkurl{check_e4_local.py}). The comparison columns of Table~\ref{tab:fix} are the same harness built against the v0.1.0 \code{strata\_core} (\nolinkurl{results/pre_fix_2026-09-28/}), against the centred engine before the significance test (\nolinkurl{results/pre_calibration_2026-09-28/}) and against the engine with the single-read-out level (\nolinkurl{results/pre_spending_2026-09-28/}):
\begin{quote}\small\ttfamily bash paper/experiments/run\_all.sh\end{quote}
  \item Tables and plot data of this paper, and the number check that maps every quantitative claim to its CSV field (see \nolinkurl{paper/arxiv_ref/NUMBERS.md}):
\begin{quote}\small\ttfamily python3 paper/arxiv\_ref/tools/make\_artifacts.py\\
python3 paper/experiments/number\_guard.py\end{quote}
\end{itemize}
Alternative backends can be replayed against the reference scenario of the unit test \nolinkurl{Integration.WallStaticMoverTransientDoorPeriodic}.
