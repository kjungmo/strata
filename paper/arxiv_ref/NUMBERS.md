# NUMBERS.md: every quantitative claim and where it comes from

Results live in `paper/experiments/results/` (written by `bash paper/experiments/run_all.sh`, seed 12345).
Tables `tables/{e0,e1,e2,e3,e3_full,e4,e5,e5_choice,e5_confusion,e5_full,fix}.tex` and `figures/data/*.dat` are generated by
`tools/make_artifacts.py` from those CSVs; no number in them is hand-typed.
`python3 paper/experiments/number_guard.py` checks both `strata_paper.md` and this package
(including that generated files are current). Last run: `PASS 394`, no failures.

**Centring fix (2026-09-28).** All E1–E3 results are from the corrected engine
(centred FreMEn coefficients, branch `fix/periodicity-centering`). The same harness
built against the v0.1.0 `strata_core` wrote `results/pre_fix_2026-09-28/`; its
periodicity-off E1/E3 and 64-window E2 files are byte-identical to the results committed
before the fix. E4 was not rerun: it runs with periodicity off, a path the fix does
not change.

**Calibrated periodic test (2026-09-28, second pass).** The engine now adds a noise-calibrated
significance test (Proposition `prop:chernoff`, nominal level δ = `periodic_false_alarm` = 0.1).
δ was chosen by E0 (`src/e0_calibration.cpp`) on seeds 20260928+, disjoint from the E1–E4 seeds
(12345 + offsets in [0, 1500]); no evaluation seed was used for tuning. The centred engine's
results before this change are archived in `results/pre_calibration_2026-09-28/`. E1 CSVs are
byte-identical after the change (the wall is constant, d = 0); E2 and E3 (periodicity on) were
rerun; E4 was not rerun (periodicity off, code path unchanged).

**Alpha spending (2026-09-28, third pass).** The shipped rule spends δ over the touch count,
δ_n = δ·T/(n(n+1)) (Proposition `prop:spend`, `PeriodicityModel::spentLevel`,
`periodic_alpha_spending = true`), and δ = 0.2 was chosen by the calibration half of E5
(`src/e5_trajectory.cpp`, seeds 30260928+) before its evaluation half ran (seeds 40260928+).
Both ranges are disjoint from E0 (20260928 + offsets < 10000), E1–E4 (12345 + [0, 1500]) and
the unit tests (800000–852000). The engine with the single-read-out level (δ = 0.1) wrote
`results/pre_spending_2026-09-28/` (E1 periodic, E2, E3 periodic). After the change E0 (which
now selects the single-read-out rule explicitly), E1 and the 64-window E2 files are
byte-identical; the E2 sweep and E3 periodic were rerun; E4 was not rerun.
